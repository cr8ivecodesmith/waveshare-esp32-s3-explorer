# Examples

**No project-maintained firmware examples have been validated or committed yet.**

The first intended example is a small modification of Waveshare's `04_gfx_helloworld` for the exact **ESP32-S3-Touch-LCD-1.54** board.

Start with the [getting-started guide](../docs/getting-started.md) and [Waveshare's Arduino example package](https://docs.waveshare.com/ESP32-S3-Touch-LCD-1.54/Arduino).

When an example is added here, include its source, dependency versions, build/flash instructions, what was tested on physical hardware, and how to restore a known firmware state. Do not silently copy upstream examples without checking their license.
