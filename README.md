# Waveshare ESP32-S3 Explorer

A collection of small projects and experiments for the [Waveshare ESP32-S3-Touch-LCD-1.54](https://docs.waveshare.com/ESP32-S3-Touch-LCD-1.54). Start with a working example, make a change, and see where curiosity takes you.

The board has a touchscreen, motion sensor, microphones, speaker, Wi-Fi, and Bluetooth LE—plenty to explore without extra components.

## Getting started

1. [Set up the development environment](docs/getting-started.md) on macOS, Linux, or Windows.
2. Build and flash Waveshare's `04_gfx_helloworld` example.
3. Change something visible on the display.
4. Explore the [project ideas](docs/project-ideas.md), or come up with your own.

The starter guide uses Arduino examples. [ESP-IDF](https://docs.waveshare.com/ESP32-S3-Touch-LCD-1.54/ESP-IDF) is another option.

## Explore

Small projects can go a long way: a shake-to-roll dice app, a focus timer, a virtual pet, a tilt-controlled game, a Wi-Fi dashboard, or a voice-controlled companion.

See the [project ideas](docs/project-ideas.md) for more possibilities. The [examples directory](examples/) will hold working projects as they're developed and tested.

## AI-assisted development

Use any coding assistant you like, or work directly with the examples. The repository includes [project guidance for coding agents](AGENTS.md) and an [optional local-context template](AGENTS.local.example.md).
