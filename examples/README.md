# Examples

This directory will contain small projects tested on the **Waveshare ESP32-S3-Touch-LCD-1.54**.

For now, begin with [Getting started](../docs/getting-started.md) and Waveshare's [Arduino examples](https://docs.waveshare.com/ESP32-S3-Touch-LCD-1.54/Arduino), especially `04_gfx_helloworld`.

When adding an example, include its dependencies, build and flashing steps, and what you observed on the board.
